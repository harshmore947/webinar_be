# Assets Directory

This directory is used for storing static assets needed by the server.

## Fonts

If you want to use custom fonts for certificate generation, place them here:

- `Arial.ttf` - For standard text
- `ArialBold.ttf` - For bold text
- etc.

The certificate generator will automatically use these fonts if available, otherwise it will fall back to system defaults.

## Other Assets

You can also store:

- Default certificate templates
- Logo images
- Watermark images
- etc.
